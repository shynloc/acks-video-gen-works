# 开关的觉醒 · 从图灵纸带到大模型 · 9:16 科普视频

一支 4 分 16 秒的竖屏科普片，讲计算机从诞生到今天的 AI。

**核心创意：画面和配乐都跟着时代一起升级。** 讲到 1936 年，屏幕是铅笔画在方格纸上的；讲到 ENIAC，屏幕变成闪烁的黑白胶片；讲到登月，画面换成绿色磷光屏；讲到个人电脑，整个画面真的降到 180 × 320 像素的 8-bit；然后是 Win95 风格的窗口、2007 年的触屏、神经网络、宣纸棋盘，一直到今天。每次换时代，都有一道扫描线从上往下把画面“重新渲染”一遍，顶部的年份计数器、“渲染引擎”标签和字幕字体也跟着换代。

贯穿全片的主角是**一个开关**：开场它只会开和关，结尾把 AI 一层层拆开（文字 → 数字 → 比特 → 开关），又回到这个开关；片尾重新写出图灵 1950 年的问题“机器，能思考吗？”，下面留一个空白输入框，“渲染引擎”标签最后变成 **“你”**。

## 声音

- **旁白**：开源 TTS [Kokoro-82M-v1.1-zh](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh)（Apache-2.0），音色 `zm_010`，语速 1.1，CPU 合成。每句用 faster-whisper 回听；据此把“ENIAC”改读“埃尼阿克”，避开 Kokoro 会读成“一个”的“亿个”（改成“超过两千亿”“千亿级的开关”），把单独念不清的“LO”改写成“刚打出 L 和 O 两个字母”。
- **配乐**（`scripts/music.py`，全部从零合成，无采样）：同一段四小节主题（A 小调 Am–F–C–G，96 BPM）在每个时代换一种乐器——八音盒 → 电子管收音机（带通 + 唱片噼啪声）→ 干净拨弦 → 模拟合成器 → 方波芯片音乐 → FM 电钢琴 + 鼓机 → 马林巴 → 氛围铺底 → 拨弦古筝（五声音阶）→ 钢琴 + 弦乐。音效（开关咔哒、铅笔、打字机、继电器、拨号上网、落子、敲钟……）由页面里的提示点驱动。旁白出现时音乐自动闪避。

## 事实核对

画面里的数字与说法均按公开资料核对：图灵 1936《论可计算数》、1950《计算机器与智能》开篇问题；ENIAC 约 17,468 根电子管、约 27–30 吨、约 167 m²，由宾夕法尼亚大学建造，六位最初的程序员姓名；1947.9.9 Harvard Mark II 日志 “1545 Relay #70 Panel F (moth) in relay. First actual case of bug being found.”；1947 年 12 月贝尔实验室晶体管；Intel 4004（1971）2,300 个晶体管，NVIDIA Blackwell B200 约 2080 亿；阿波罗导航计算机 2048 字 RAM（约 4 KB）；1969.10.29 UCLA → SRI（约 560 km）发送 LOGIN 时崩溃；1991 年 info.cern.ch 首页原文；深蓝 1997 年以 3½ : 2½ 获胜，每秒约 2 亿个局面；1956 达特茅斯会议；AI 寒冬（1974、1987 前后）；AlexNet 2012 ImageNet top-5 错误率 15.3%（第二名 26.2%），两块 GTX 580 训练；AlphaGo 2016 年 3 月首尔 4 : 1，第二局第 37 手；Transformer 2017；ChatGPT 约 2 个月达到 1 亿用户（Instagram 约 2.5 年、TikTok 约 9 个月，为广泛引用的估算）。

示意性质的画面都有标注：晶体管对比条、围棋棋局、“你好”的编号与二进制编码。

## 技术

- 渲染管线沿用仓库根目录的 `scripts/render.mjs`：页面暴露 `renderFrame(t)`，每一帧都是 t 的纯函数，Playwright 逐帧截图，ffmpeg 编码。
- 旁白是时钟：`tts.py` 写出 `timeline.json`（每句起止），画面用 `c.W(行, '词')` 在某个词被念出的那一刻触发。
- 代码：`src/main.js`（时间轴、HUD、扫描线换代转场），`src/scenes-early.js`（序章 → 1969），`src/scenes-late.js`（像素 → 现在，含 1-bit 像素字引擎），`src/lib.js`（缓动、确定性噪声、提示点）。
- 8-bit 段落真的是在 180 × 320 画布上画的，文字按原生像素尺寸光栅化后二值化，再用 `image-rendering: pixelated` 放大 6 倍。
- `scripts/check_subs.mjs` 用每个时代自己的字幕字体量宽度，超出字幕条就中止构建。

## 重新构建

```bash
npm install                                  # 仓库根目录：字体、emoji 图片、Playwright
pip install -r requirements.txt              # 仓库根目录：Pillow / NumPy / SciPy / imageio-ffmpeg
bash computer-to-ai/scripts/build.sh         # 复用已有旁白
bash computer-to-ai/scripts/build.sh --tts   # 重新配音（需要 ../jintaoblog-611/requirements-tts.txt 的环境）
```

预览单帧：`node scripts/render.mjs --project computer-to-ai --stills 20,60,120`

## 素材与许可

字体均为 OFL（npm `@fontsource`），emoji 为 Google Noto Emoji（Apache-2.0，npm `emoji-datasource-google`），旁白模型 Apache-2.0；画面、配乐、音效全部由代码生成，没有第三方图片、视频或音频素材。
